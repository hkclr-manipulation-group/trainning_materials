# 操作卡3：把“能动”调成“按要求动”

[单电机卡](02_motor.md) → 本卡 → [工位交付表](../templates/MOTOR_COMMISSIONING.md)

开始条件：接线、反馈、方向、限值及停止已验证。目标是用同条件记录解释一次参数修改的效果。首次调试先采用厂家对应电机的推荐参数；电流环、换相、电机辨识按厂家专用流程完成。

## 1. 先确定正在调哪个控制器

**闭环**就是反复测量、与目标比较、再纠正。**误差**是目标减实际值。**位置环**依据角度误差产生速度或力矩要求；**速度环**依据速度误差产生力矩/电流要求；**电流环**调节电流。具体嵌套关系取决于驱动器，位置模式中很多环已在驱动器内部实现。

先画出“程序发什么→驱动器在哪种模式→反馈什么”。如果电脑发目标位置，就先调轨迹限速、加速度和厂家允许的位置参数；只有明确选择速度接口并设计了外部位置环时，才在电脑端用角度误差算速度。两者的参数单位不同。

例如教学外部位置P环：`e=q_ref-q`，`v_cmd=clip(Kp*e,-v_max,v_max)`。若角度单位为度、输出为度/秒，Kp单位就是1/秒。假设误差2°、Kp=0.5/秒，输出为1°/秒，再由速度上限裁剪。这个数值只用于理解计算，不是实物推荐值。

## 2. 把PID翻译成观察动作

| 项 | 做什么 | 观察什么 |
|---|---|---|
| P，比例 | 当前误差越大，纠正越大 | 响应变快时，是否开始超过目标或来回摆动 |
| I，积分 | 累积一段时间的误差 | 是否减少持续偏差；输出受限后是否仍继续积累 |
| D，微分 | 根据变化率调节，可增加阻尼 | 是否减轻摆动，同时把测量噪声放大 |
| 限幅/饱和 | 指令最多只能到边界 | 长期顶住边界时，应查目标、负载和限制，而非一直加增益 |
| 积分抗饱和 | 输出受限时限制积分累积 | 脱离限制后是否还长时间向同一方向推 |

实际数字PID的积分要乘采样周期，微分要除采样周期。采样周期是两次控制计算之间的时间；程序写`sleep`并不保证真实间隔恒定。电脑、总线和驱动器延迟都可能影响控制，记录实际时间间隔。完整计算见[控制手册](../handbook/03_control.md)。

## 3. 先规定什么叫“调好了”

把目标、反馈和电流按同一时间轴画图，至少记录`t、q_ref、q、v、current、mode、fault`，补上单位和无效字段。若工具只导出部分数据，在记录里明确缺项。

**超调**是实际值超过目标；**稳态误差**是运动稳定后的剩余差距；**调节时间**是进入允许误差带并持续满足条件所需的时间。不要用一次穿过目标就宣称到位。

教学例：目标从0°变为10°，峰值11°，超调量1°，相对这次10°变化为10%。若要求误差不超过0.2°并保持0.5秒，则9.85°这个单点还不能证明通过，必须检查后续连续有效反馈。真实允差、保持时间和电流上限写在试验前的交付表中。

## 4. 一轮调参只改变一个因素

1. **存基线。** 备份参数、记录负载与起点，用已验证的小范围轨迹重复运行，保存原始数据。先排除松动、摩擦异常、错误单位和反馈丢失。
2. **调运动要求。** 如果加速时电流长期顶到限制，先检查负载与加速度要求。先得到供电和机械条件能执行的轨迹，再讨论增益。
3. **选要改的环和参数。** 厂家工具按其调参顺序操作。离线自建PID可先理解P，再逐项理解D和I；不要在真实多环驱动器中直接把所有I、D清零。
4. **小步修改并重复。** 一次只改一个允许修改的参数，记录旧值、新值和单位；同一轨迹、起点、负载、采样设置下对比。出现振荡、异常电流或温升就停止，恢复上一份已验证配置并找原因。
5. **用指标决定保留。** 比较超调、调节时间、持续误差、电流与故障。不能只因为声音变小或速度变快就接受。
6. **复测完整行为。** 新参数通过后重新确认正反向、停止及超时处理。保存配置前查明写入的是RAM临时参数还是非易失存储；不要把每次试验都写入永久存储。

首次工位不要通过“故意加大增益直到持续振荡”寻找边界；这不适合未知负载、间隙和停止行为的系统。调参记录应允许回退到上次通过的设置。

## 5. 没有硬件也能先练读曲线

在训练资料根目录运行现有离线实验：

```text
python labs/algorithm_lab.py --help
python labs/algorithm_lab.py pid
```

运行前查本机帮助确认命令。模型与真机不同；先从[控制手册](../handbook/03_control.md)读清教学模型，再解释实验输出。算例增益不能直接复制给真实驱动器。

自检：目标不动，反馈噪声变大时D项可能怎样？限幅期间积分不断增长会怎样？答案：D项可能放大高频噪声；积分可能积累过多，解除限幅后仍造成过度纠正。分别检查滤波与采样、积分抗饱和，同时保留原始反馈以免把问题隐藏。

最终交付：至少一组原参数与修改参数的同条件记录，解释为什么保留或回退；由同事按[工位交付表](../templates/MOTOR_COMMISSIONING.md)复现最小操作。
