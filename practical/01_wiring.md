# 操作卡1：从认接口到上电读状态

[实操路线](../PRACTICAL_PATH.md) → 本卡 → [单电机调试](02_motor.md)

目标：搭好一个固定在工装上的低压直流单电机工位，检查供电和CAN连接。需要电机及其驱动器、匹配的适配器和线束、设备指定电源、万用表、固定工装，以及该型号手册和连接器针脚图。裸电机外接驱动器时，先按厂家流程配置相线、编码器、抱闸和电机辨识；本卡不能代替这些型号专用步骤。

## 1. 先会认这几个词

| 词 | 直观解释 | 手上怎么确认 |
|---|---|---|
| 电压V | 两点之间的电位差，电源要与设备要求匹配 | 看铭牌范围，再在正确两点间测量 |
| 电流A | 流过线路的电荷流率，线路和电源都有承受范围 | 首次上电观察电源电流显示；不把电流档跨接电源 |
| 电阻Ω | 对电流的阻碍程度 | 电阻和通断测量前先断开所有供电并确认无电压 |
| 驱动器 | 接收目标并调节电机电流的硬件 | 找到动力输入、电机输出和通信接口 |
| 引脚定义pinout | 每根针的编号及用途 | 确认图是看插头还是插座、插合面还是焊线面 |
| CAN_H / CAN_L | CAN差分信号的两根线 | 按信号名核对两端，不按线颜色猜 |
| 终端电阻 | 放在总线物理两端、减小反射的电阻 | 核对适配器和电机是否已经内置或打开终端 |
| 使能enable | 允许驱动器输出的状态 | 从状态反馈确认，亮灯或有电不等于使能 |

供电负极、信号参考地、机壳和保护地可能在设备内相连，也可能隔离。按设备的隔离与接地方案连接，不能看到“GND”就把所有位置短接。

## 2. 断电前先把接线画出来

先填[工位交付表](../templates/MOTOR_COMMISSIONING.md)。每条线写“设备A的连接器、针号、信号→设备B的连接器、针号、信号”；照片须看得见编号或标签。确认针号的观察方向，避免镜像接反。

```text
电脑 ──USB── CAN适配器
               CAN_H ───────────── 电机驱动器 CAN_H
               CAN_L ───────────── 电机驱动器 CAN_L
               参考地/屏蔽：按两端设备的隔离与接地方案连接
指定直流电源 ──工位保护与停止回路── 驱动器动力输入
```

这是信号示意，不是某块板子的针脚图。H接H、L接L的前提是两端都是CAN总线口；MCU的CAN_TX/CAN_RX需要收发器，不能直接接到这里。

常见高速CAN在线路两端各放一个120Ω终端，其余节点不额外添加。见[TI终端参考设计](https://www.ti.com/tool/TIDA-01238)。仅当实际电路是两只120Ω并联、已断电且没有其他影响测量的支路时，H与L之间应接近60Ω；约120Ω可能少了一端，约40Ω可能多了一只。结果不符时检查拓扑和内置终端，不能只凭一个阻值判断电机好坏。其他物理层和分裂终端查设备图纸。

## 3. 按顺序做，不跳到运动指令

| 步骤 | 操作 | 预期结果 | 不符时检查 |
|---|---|---|---|
| A 固定工位 | 固定电机，清空输出轴活动范围；有重力负载先支撑并确认抱闸流程 | 输出运动或失能都不会带来失控下落 | 工装、负载和停机后的机械状态 |
| B 断电接线 | 关闭并隔离动力及USB等可能反向供电的来源，确认无电压后接线；按图逐针查通断 | 信号去向与表一致，无意外短接 | 接口朝向、压接、裸线、屏蔽处理 |
| C 检查终端 | 在设备允许的断电条件下测H-L电阻，记录测点和读数 | 与该工位终端方案吻合 | 内置电阻开关、缺线、多余节点 |
| D 检查电源 | 电机断开时按电源说明设置电压与限流；用直流电压档并联测输出极性，再断电接入电机 | 极性与设备范围正确，限流取自工位参数表 | 表档和插孔、电源设置、线束针号 |
| E 仅上电观察 | 按设备规定顺序上电，保持未使能；观察电压、电流和故障状态 | 供电稳定，状态符合手册，无异常发热或气味 | 接反、短路、欠压、上电浪涌触发限流；异常先断电排查 |
| F 建立通信 | 选适配器通道、速率、经典CAN/CAN FD与帧类型，发送该设备已核实的只读请求 | 返回匹配ID和命令的完整状态 | 进入下一张卡按层排查 |

万用表不会使用时，先让熟悉仪表的同事演示表笔插孔、直流电压档和断电通断测量，再由学员复述并操作。停止回路必须说明触发后是减速、失能还是切断动力，以及抱闸如何配合；软件窗口关闭不能代替工位停止功能。

## 4. 本卡怎么过关

交付逐针接线表、带标注照片、供电与终端测量记录、未使能状态截图。让同事在断电状态按图找到CAN_H、CAN_L和动力输入。

自检：USB适配器被识别，是否说明电机已供电？H-L测到60Ω，是否证明通信速率正确？答案均为否；前者仅证明电脑到适配器的一部分链路，后者只是特定电路的断电电阻检查。
