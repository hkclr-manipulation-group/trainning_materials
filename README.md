# 机器人开发入门

从两根纸条做的机械臂开始，认识结构、通信、运动、避障和感知，最后做一个输入角度、输出位置的小工具。

**从[第一课](lessons/day01_system_and_code.md)开始**，或先看[学习路线](WEEK_PLAN.md)。共七课，按自己的节奏推进；每课读一个主题、做一个实验，再用三道题检查理解。

## 动手之前

准备纸、笔和计算器。例子统一使用30厘米与20厘米的两根杆，没有电脑也能先做手算。

要运行代码，按[交互课堂](INTERACTIVE.md)安装，之后双击 `start_classroom.cmd` 打开本机课堂。也可以直接看[逐步演示](assets/interactive/concept_player.html)，无需安装。

不熟悉单位和坐标时查[数学小台阶](beginner/MATH_STEPS.md)，不会运行程序时查[电脑操作卡](beginner/COMPUTER_FIRST_STEPS.md)。遇到问题可看[自学提示](SELF_STUDY.md)。

公式推导、专业工具、工程训练和参考文献统一放在[扩展资料](EXTENSIONS.md)，用到时再读。
