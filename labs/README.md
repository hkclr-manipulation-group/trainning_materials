# 六个离线实验

基础实验之外，继续做 [五个算法实验、原生交互窗口与离线通信数据练习](ALGORITHMS.md)。图解见 [图示索引](../assets/README.md)。

在培训仓库根目录运行下列命令。Python 3.10+，标准库即可。输出写入本仓库 `outputs/`；从其他工作目录启动脚本时，输出位置仍相同。所有参数都是教学值。

| 实验 | 命令 | 预期结果 | 自己改变什么 |
|---|---|---|---|
| 单位 | `python labs/course_lab.py units` | 90°≈1.5708 rad；300 mm=0.3 m；100 Hz→0.01 s | 再计算 180° 和 50 Hz |
| FK/IK | `python labs/course_lab.py kinematics` | 目标约 (0.259808,0.35) m；复算误差<1e-12 m | 改为外部目标 (0.6,0)，无几何解 |
| 协议 | `python labs/course_lab.py protocol` | `a1 01 07 00 fa 00 00 00`；反馈过期 | 负角度、短包、未知标记 |
| 控制 | `python labs/course_lab.py control` | 终值接近 1 rad，速度≤0.5 rad/s，输出 CSV | 比较不同 kp；记录实际时间 |
| 碰撞 | `python labs/course_lab.py collision` | 真实区间间隙+4 mm，大球间隙−10 mm | 计算半径变化带来的间隙变化 |
| 小型学习 | `python labs/course_lab.py ai` | 留出集误差低于常量基线 | 改变训练样本，保持测试集不动 |

## 操作流程

先手算或预测结果，再运行并比较。改变函数默认参数前，保存原始结果；修改后再次运行对应实验。每个实验提交“预测、命令、观察、解释、限制”五项，不需要大量截图。

控制 CSV 的每一行记录时刻 t 的状态与随后一个 dt 使用的速度指令；报告的终值是最后一次更新之后的状态，因此不等于 CSV 最后一行的位置。图中必须标注秒、弧度、弧度每秒。

通信实验仅对内存字节做编码解码，没有发送 CAN、USB 或网络报文。它不模拟仲裁、CRC、真实驱动和电机状态。AI 实验的训练和测试观测互不重叠，教学任务固定，因此没有超参数选择所需的验证集；自行比较多种模型时应另设验证集。

## 运行验证

```powershell
python labs/course_lab.py all
python -m unittest discover -s tests -v
```

测试覆盖手算位置、几何不可达、固定字节向量、负数、坏包、超时边界、控制限速与收敛、球接触、回归的已知解和退化输入。测试通过只支持这些离线行为，不支持硬件控制结论。
