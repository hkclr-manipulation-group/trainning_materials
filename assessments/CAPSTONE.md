# 结业任务：离线机器人诊断小工具

时间：第7天完成初版，最后1小时自测、复现与整理说明。基础较弱者可使用本仓库函数，不要求重新实现全部算法；按评分表自评，也可请同事查看结果。

## 任务

新增一个命令行工具，读取自定义 JSON 输入，输出机器可读的诊断 JSON。至少支持：两连杆 FK 或 IK、教学协议解码、一个明确的非法输入错误。输出包含字段单位、结果状态和失败原因。提供两个输入样例和 README，并用独立预期值测试。

建议输入：

```json
{
  "joint_rad": [0.0, 1.5707963267948966],
  "link_m": [0.3, 0.2],
  "payload_hex": "a1 01 07 00 fa 00 00 00"
}
```

预期末端约 `(0.3,0.2) m`，解析角度 `0.25 rad`。再提供缺字段、负杆长或错误报文长度的样例，工具应明确拒绝并返回非零退出码。不得把失败伪装为零坐标或成功状态。

可选加分方向：教学日志的重复序号统计；控制 CSV 的最大速度与误差分析；模型配置的单位和限位报告。扩展不替代核心任务。

## 评分表

| 项目 | 分值 | 依据 |
|---|---:|---|
| 需求与接口 | 15 | 字段、单位、成功与失败行为明确 |
| 功能正确 | 25 | 正常结果符合手算，坏输入被拒绝 |
| 测试 | 20 | 至少 4 个有效测试，含固定预期和异常 |
| 复现与工具使用 | 15 | 清晰命令、输出、环境、diff |
| 工程解释 | 15 | 能解释层次、假设和未覆盖条件 |
| AI 协作记录 | 10 | 保留任务、关键建议、人工核对和修正 |

通过线70/100，另有三个必过项：单位无混淆；非法输入不返回成功；如实区分离线与真机验证。自己复制到另一目录重跑，不依赖原目录绝对路径或其他仓库；可选请同事复现。

自测追问：若输入来自相机还缺什么？若报文已发送但反馈过期如何表示？如果碰撞球误判，应改数据、算法还是忽略规则，依据是什么？
