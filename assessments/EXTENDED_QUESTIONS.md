# 扩展自检：会解释机制、比较方法和限定结论

先独立回答，再看每题解析。不要求第一周全部完成；每题能给出正确判断和理由各记1分，共40分。错题回到[深度地图](../DEPTH_MAP.md)中的相应专题，重新运行最小实验。

## 通信

1. 电机通过USB桥接到CAN，电脑已识别USB设备，能否说明电机已收到命令？

   **解析：** 不能。USB枚举只支持该观察点的部分连接判断；还需桥接解析、SPI事务、CAN发送/错误计数以及目标反馈等证据。

2. 一条8B应用消息经过本课UDP/IPv4/Ethernet捕获示例为什么变成50B？是否等于真实线上只发送50B？

   **解析：** 8+8+20+14=50；这是特定合成捕获记录，未包含全部真实链路填充、FCS和其他开销。

3. 发送端写ABC、DE，接收端先读A再读BCDE，TCP是否损坏了消息？

   **解析：** 没有这个证据。TCP提供字节流，应用需分帧；按本课长度前缀和缓冲区可恢复两条消息。

4. 同时发送标准数据帧0x120和0x100，限定只看11位ID，谁在哪位退出？

   **解析：** 0x120在bit5发1而读到显性0，退出；0x100继续。完整CAN仲裁还包含本实验未模拟的其他情况。

5. 为何历史里CAN会同时出现1986和1991？

   **解析：** 这里分别指公开介绍与量产应用阶段，不是同一事件两个互相矛盾的日期。历史应标注事件类型和来源。

## 逆运动学

6. 几何法和代数法都得到两杆c2公式，是否说明其中一个是假的不同算法？

   **解析：** 不是。两种推理路径描述相同机构约束；几何构造与方程消元可在该结构上得到相同关系。

7. 两个正确IK解的普通关节平均为何可能错？

   **解析：** FK是非线性映射，解集一般不是凸集合。本例q2平均为0后手臂伸直，位置误差约139.4mm；还应考虑周期角表示。

8. “有n个关节、m个任务量，所以解集一定n−m维”错在哪里？

   **解析：** 缺少局部正规点、满行秩等条件；奇异点、限位边界和离散分支会改变情况。

9. DLS增大λ会带来什么？

   **解析：** 抑制小奇异值方向上的大更新，但也改变更新幅度与误差折中，可能更慢；不是无代价地解决所有奇异和局部极值。

10. 为什么最近邻数据库对(.6,0)m也能返回q，却不能说目标可达？

    **解析：** 非空数据库总能给最近的样本，但两杆最大半径只有.5m。必须检查FK残差和任务条件。

11. 学习IK应仅比较预测q与某个标签q的均方误差吗？

    **解析：** 不足。同一目标可能有多个正确q；还要看FK位姿残差、限位、碰撞、多样性和时延，并规定分支及数据拆分。

## 工具与软件

12. git commit成功后，网页上为什么可能看不到？

    **解析：** 提交发生在本地；还涉及push、远端地址、分支与网页查看位置。不能把保存文件、commit和push混为一件事。

13. 主分支从mm改m，你的分支把长度300改350，合并应保留300、350还是.35？

    **解析：** 若两项意图都有效，米单位下是.35。先理解意图，再检查所有接口与FK，而非只选一侧文本。

14. CI全绿能证明机器人不会碰撞吗？

    **解析：** 不能。它只支持实际配置并运行的检查；本课模板主要检查离线算法与链接，没有进行真实几何和硬件验收。

15. 数据集换了，但代码没换，是否属于同一次可复现实验？

    **解析：** 不能默认相同。要记录数据版本/哈希、配置、拆分、环境与结果；代码版本只是其中一部分。

## 其他主题

16. 0.5kg载荷在.3m水平力臂，另有.2kg杆质心在.15m，取g=9.81，已知两项静力矩总和是多少？

    **解析：** .5×9.81×.3+.2×9.81×.15=1.7658N·m。尚未计入其余结构、动态、摩擦或效率，不能直接当电机额定选型结论。

17. 对无延迟教学积分器，dt=.01、Kp=12，误差每步乘什么？增加8步反馈延迟后还能照搬吗？

    **解析：** 乘.88；有延迟后依赖更早状态，不能继续用同一个一阶递推。真实电机还会有其他动态。

18. A*动画里的蓝格是候选队列吗？目标格无碰撞是否证明整条机器人路径无碰撞？

    **解析：** 新动画蓝格是已扩展集合；候选队列另有含义。终点检查不能替代边和整个运动过程的碰撞检查。

19. RANSAC中w=.5、s=3，独立抽样假设下希望至少.99概率抽到全内点样本，为什么约需35次？

    **解析：** 解1−(1−.5³)^N≥.99，得到N≥ceil(log(.01)/log(.875))=35；退化样本或错误模型仍会失败。

20. 为什么更平滑的估计不一定更适合快速控制？

    **解析：** 平滑常伴随响应滞后，突变或快速运动时会产生过时估计；还需评价误差、时延和模型假设，不能只看曲线外观。
