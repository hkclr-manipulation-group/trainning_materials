# 工程阶段考核：用证据说明会做什么

[工程课程](../ENGINEERING_PATH.md) · [报告模板](../templates/ENGINEERING_LAB.md)

每门提交正常案例、一个失败案例和修正前后记录。下面是判断要点，不能只抄答案代替操作。

| 门类 | 必做问题 | 判断依据/参考答案 |
|---|---|---|
| 数学与误差 | 0.5m力臂、0.1°零偏对应多大位移？精度能靠提高编码器位数解决吗？ | 小角度约0.873mm；分辨率之外还需查系统偏置、传动与时序 |
| 本体 | 0.8kg在0.4m、0.6kg均匀杆长0.3m，水平静止力矩与惯量？ | 4.0221N·m；约0.146kg·m²，不含其他机构，不能直接当完整选型 |
| 接口 | TCP一次收到两帧半，怎样处理？ | 提取两条完整消息，保留残余直到后续完整或超时/断开，长度需校验 |
| CAN FD | 9字节应用长度对应何种DLC和容量？配置5M数据速率是否证明用了BRS？ | DLC9、12字节；不证明，检查发送标志与总线记录 |
| CAN FD | 6轴1kHz，每轴双向各32字节，仅载荷需要多少带宽？ | 3.072Mbit/s；相对5M为61.44%，尚未加协议与调度开销 |
| EtherCAT | `27 00 18 fc ff ff`按本课PDO怎样读？OP能否等同电机使能？ | 状态0x0027、位置-1000；总线与驱动两套状态不能混为一谈 |
| EtherCAT | WKC期望6、实际4，旧位置还在内存中，可否刷新成新反馈？ | 不可；保留旧记录及时间，当前周期标无效并按策略处理 |
| 运动学 | IK成功但FK误差大；另一seed却正确，如何验收？ | 分别核对单位/模型/残差/分支/约束，不以单个success字段验收 |
| 控制 | 平均周期1ms，偶尔计算2ms；是否满足1kHz要求？ | 平均值不足，查截止违例、最大迟到、连续丢周期与执行后果 |
| 规划 | 起点终点都有效，可否直线执行？ | 需检查中间状态/边、时间参数化、当前场景与实际几何 |
| 感知 | 0.2m/s运动中错用晚40ms的姿态，可能增加多少误差？ | 匀速纯平移模型下8mm；旋转和时钟偏差另算 |
| AI | 同一episode的相邻帧随机拆训练/测试，为什么结果不可信？ | 高相似与共同场景泄漏；整段/场景/采集批次分组并保留独立测试 |
| 软件 | 故障后通信恢复，旧动作能否自动继续？ | 不能仅靠恢复通信决定；重新验证状态与目标、显式恢复到允许运行条件 |

## 综合任务A：通信到控制

任选一套实际CAN FD或EtherCAT工位，完成身份、接线、配置、只读反馈、有限运动、停止与恢复。再解释另一种总线在配置、有效性、同步与排错上的差异。交付既要有原始帧/过程数据，也要有解析值和时间线。

若没有某种硬件，该部分完成离线解码与状态故障题，并明确工位实测未通过/未验证；不把仿真成功算成两种总线都已调通。

## 综合任务B：模型到任务

固定模型/工具/标定版本，给一个已知目标建立感知到基座转换，求IK并复算，检查路径和时间参数，记录控制跟踪与最终独立测量。注入一项故障：过期图像、错误TCP、薄障碍漏检或旧动作重放，定位到正确层。

## 评分依据

各门按五项各0–2分记录：解释、计算、实施、排错、复现。0为没有证据，1为能在帮助下完成，2为独立完成并解释限制。涉及硬件的操作验收单独列结果，不能用文字得分补偿关键工位项目未验证。复核者写出还缺哪份证据及下一步，而不是只给“合格”。
